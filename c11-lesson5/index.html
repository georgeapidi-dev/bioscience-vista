STEP 2 · EXPLORE

Competitive and non-competitive inhibition

15 min
Memory hook: ALLO-steric = 'other' site → changes the shape elsewhere
CompetitiveNon-competitive
Binds toActive siteAllosteric site
ShapeSimilar to substrateNot similar to substrate
How it inhibitsBlocks substrate from active siteChanges shape of active site
Effect of more substrateOvercomes inhibition – max rate reachedCannot overcome – max rate lowered
ExampleStatins (HMG-CoA reductase)Isoleucine on threonine deaminase; ATP on PFK
Memory hook: Competitive = Copycat in the Centre · Non-competitive = Not there, Nudges shape
Worked example Explain why the effect of a competitive inhibitor, but not a non-competitive inhibitor, can be reduced by increasing substrate concentration. [3]
Model answer
  • Competitive inhibitor binds to the active site/competes with substrate ✓
  • more substrate molecules → substrate more likely to collide with/occupy active sites than inhibitor ✓
  • non-competitive inhibitor binds to an allosteric site changing the active site, so substrate cannot bind however much is added ✓

STEP 4 · EXPLAIN

Feedback inhibition and penicillin

20 min
Memory hook: The end product puts the brakes on the first enzyme.
Worked example Explain how isoleucine regulates its own synthesis. [3]
Model answer
  • Isoleucine (end product) binds to the allosteric site of threonine deaminase, the first enzyme of the pathway ✓
  • this changes the shape of the active site so threonine cannot bind / pathway stops ✓
  • when isoleucine levels fall it detaches (reversible) and the pathway resumes – negative feedback ✓
Memory hook: Penicillin = Permanent: it Plugs the transPeptidase for good.
Worked example Explain how a mutation in a bacterium can make it resistant to penicillin. [2]
Model answer
  • Mutation changes the amino acid sequence/shape of the transpeptidase active site ✓
  • penicillin can no longer bind, but the enzyme can still form cross-links, so the cell wall is still made ✓
