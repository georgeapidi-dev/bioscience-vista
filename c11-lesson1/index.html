STEP 2 · EXPLORE

Why do cells need enzymes?

15 min
Memory hook: CAT-alyst → Changes the rate · Always reused · Tiny amounts needed
Worked example Hydrogen peroxide (H₂O₂) is a toxic by-product of metabolism. A bottle of H₂O₂ decomposes slowly over months, but in liver cells it is destroyed in a fraction of a second. Explain the benefit of catalase to the cell. [2]
Model answer
  • Catalase is a catalyst that greatly increases the rate of H₂O₂ breakdown (into water and oxygen) ✓
  • so toxic H₂O₂ is removed before it can damage cell components / at body temperature without denaturing cell proteins ✓
Memory hook: MAC: Metabolism = Anabolism + Catabolism
Worked example Explain why living organisms need many different enzymes. [2]
Model answer
  • Enzymes are specific: each active site is complementary to (fits) only one / a few substrates ✓
  • metabolism involves thousands of different reactions, so a different enzyme is needed for each reaction ✓

STEP 3 · TEST

Anabolic or catabolic? Test your rules

15 min
AnabolismCatabolism
What happensBuilds macromolecules from monomersBreaks large molecules into smaller ones
Typical reactionCondensation (water released)Hydrolysis (water used) / oxidation
EnergyRequired (endergonic)Released (exergonic)
IB examplesProtein synthesis, glycogen formation, photosynthesisDigestion of macromolecules, respiration
Memory hook: Anabolic = Assemble (Add) · Catabolic = Cut (Crumble)
Worked example Classify the formation of glycogen in the liver and the digestion of starch in the small intestine as anabolic or catabolic, and name the type of reaction involved in each. [2]
Model answer
  • Glycogen formation is anabolic – condensation reactions link α-glucose monomers ✓
  • Starch digestion is catabolic – hydrolysis reactions split starch into maltose/glucose ✓

STEP 4 · EXPLAIN

Why does the whole protein matter?

15 min
Memory hook: Few to bind, all to hold: a FEW amino acids form the site, ALL the others hold it in shape.
Worked example A mutation replaces one amino acid located far from the active site of an enzyme. The enzyme no longer catalyses its reaction. Suggest why. [3]
Model answer
  • The R-group of the new amino acid forms different bonds / interactions ✓
  • so the tertiary (3D) structure of the enzyme changes ✓
  • which alters the shape/chemical properties of the active site so the substrate no longer binds ✓
